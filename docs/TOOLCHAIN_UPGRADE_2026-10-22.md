# Обновление toolchain: Tailwind CSS 4 + Vite 8 (2026-10-22)

## Что сделано

- **Tailwind CSS 3.4 → 4.3.3** официальным инструментом `@tailwindcss/upgrade`:
  - тема переехала из `tailwind.config.js` в `@theme` внутри `src/index.css`
    (те же цвета `bg-primary`, `accent`, `positive`, …, `radius-xl2`, анимации);
  - файл `tailwind.config.js` удалён, `autoprefixer` удалён;
  - PostCSS-плагин заменён на `@tailwindcss/postcss`;
  - утилиты в компонентах переименованы инструментом (`outline-none` → `outline-hidden`,
    `bg-gradient-to-*` → `bg-linear-to-*`, `bg-white/[0.045]` → `bg-white/4.5` и т.д.);
  - добавлен совместимый базовый слой цвета границ (v4 default = `currentColor`).
- **Vite 5.4 → 8.3.5**, `@vitejs/plugin-react` 4.3 → 6.1.2.
  - Rolldown принимает `manualChunks` только функцией — `vite.config.ts` переписан
    с сохранением чанков `charts` / `animation` / `supabase`.
  - В `package.json` добавлен `"engines": { "node": "22.x" }` для Vercel.
- Остальные dev-зависимости обновлены в пределах своих мажорных версий свежим lockfile
  (lockfile сгенерирован npm 12: npm 10.8 падает на этом дереве с ошибкой `edgesOut`;
  `npm ci` со стандартным npm по готовому lockfile работает — проверено).

## Проверки

- `npm ci` (стандартный npm 10.8) — успешно, 0 уязвимостей;
- `npm run typecheck` — успешно;
- `npm run lint` — успешно;
- `npm run build` — успешно;
- сверка классов: все кастомные классы темы присутствуют в новом CSS; отсутствующие
  из старого CSS — только переименованные эквиваленты и неиспользуемые утилиты;
- smoke-test: статика `dist/` раздаётся, все JS/CSS ассеты отвечают 200.

## Нюансы

- Если в репозитории после загрузки останется старый `tailwind.config.js`, сборке он
  не мешает (Tailwind 4 его не читает без директивы `@config`) — удалить можно позже.
- Чанк `supabase` вырос (≈203 КБ): `@supabase/supabase-js` обновился в пределах `^2`
  до актуальной версии. Функционально нейтрально.
- TypeScript сознательно оставлен на ветке 5.x (актуальная 5.9.3 через диапазон),
  ESLint — на 9.x: переход на TS 7 / ESLint 10 — отдельная задача без срочности,
  уязвимостей они не дают.
