# Market Pulse: фирменная идентификация, производительность и UX

Дата: **23 октября 2026 года**.

## Короткий итог

Внешние замечания другого ИИ были проверены по фактическому коду. Часть
предложений уже существовала (липкая навигация, мобильное меню, несколько
фильтров и состояний), часть была полезна и реализована, а тяжёлые или
рискованные переделки не понадобились.

Главное изменение для посетителя: у Market Pulse больше нет generic/Bolt-era
картинки при отправке ссылки. Сайт получил собственный знак, favicon,
PWA-иконки и OG-превью в тёмно-синей гамме проекта.

## Что реализовано

### 1. Фирменный знак и превью ссылки

- `public/favicon.svg` — новый знак: пульс события переходит в рыночный
  импульс со стрелкой; градиент cyan → blue → violet → emerald.
- `public/logo.svg` — горизонтальная версия знака.
- `public/icon-192.png`, `public/icon-512.png`,
  `public/apple-touch-icon.png` и `public/site.webmanifest`.
- `public/og-image.svg` — редактируемый исходник карточки 1200×630.
- `public/og-image.png` — новая PNG-карточка: «Мировые события → рынки →
  Россия», «Сайт запоминает сигналы и проверяет их реальным движением цен».
- `src/components/BrandMark.tsx` — тот же знак в шапке и подвале вместо
  стандартной Lucide-иконки `TrendingUp`.
- В `index.html` обновлены title, description, canonical, robots,
  Open Graph и Twitter Card; OG-изображение получило параметры 1200×630,
  alt-текст и cache-busting `?v=20261023`.
- Служебная папка `.bolt` удалена из подготовленного дерева проекта: она не
  нужна runtime-коду. На работу сайта это не влияет.

### 2. Производительность

- Recharts полностью удалён из зависимостей. История Tension теперь
  рисуется лёгким собственным SVG с сеткой 0–100, точками, подсказкой,
  клавиатурным фокусом и цветом по абсолютному значению индекса.
- В production-сборке больше нет отдельного `charts`-чанка.
- `NewsFeed`, `Forecasts`, `MarketMemory`, `AboutProject` и
  `AnalyticsGuide` вынесены в отдельные lazy-чанки.
- Секции ниже первого экрана монтируются при приближении к viewport.
  Placeholder сохраняет тот же `id`, поэтому якоря и scroll-spy работают
  ещё до загрузки тяжёлого содержимого.
- Прямые ссылки вида `#market-memory`, `#about` и `#guide-memory`
  специально дожидаются появления целевого элемента и корректируют
  прокрутку после расширения страницы.

### 3. Навигация и мобильная версия

- Scroll-spy перечитывает реальные позиции секций при прокрутке и не
  теряет подсветку после замены placeholder настоящей lazy-секцией.
- На мобильных добавлена нижняя быстрая навигация: Обзор, Россия,
  Новости, Сигналы, Память, Гид.
- Нижняя навигация вынесена из `header`: `backdrop-filter` шапки создавал
  containing block, из-за чего `fixed bottom` после прокрутки мог
  прыгнуть наверх. Позиция проверена Playwright на 375×812.
- Добавлены `scroll-padding-top`, `overflow-x: clip` и уважение к
  `prefers-reduced-motion`.

### 4. Полезные фильтры

Лента новостей:

- источник;
- тема;
- актив влияния;
- тональность;
- минимальная важность 6+, 8+ или 9+;
- счётчик активных фильтров и результатов;
- кнопка сброса;
- на мобильных панель сворачивается под кнопку «Настроить».

Память рынка:

- фильтр событий по каналу передачи;
- фильтр по активу в сохранённой цепочке влияния;
- количество событий в каждой чип-кнопке;
- сброс и отдельное пустое состояние.

Фильтры не меняют данные и не пересчитывают исходы — они только выбирают
уже сохранённые карточки.

### 5. Честные состояния загрузки, stale и ошибок

- Tension больше не показывает демонстрационное значение как живое:
  - первая загрузка — skeleton;
  - нет живых данных — ошибка с кнопкой повтора;
  - обновление не удалось после успешной загрузки — явная плашка
    «последнее успешное значение» с временем и retry.
- Мировые цены различают:
  - живые данные ещё ни разу не получены;
  - показан последний успешный живой снимок;
  - отдельная плитка не получила свежую цену и помечена нейтрально
    «нет свежей цены».
- Новости, сигналы и память рынка получили skeleton-состояния, понятные
  ошибки, ручной повтор и stale-плашки без затирания уже показанных данных.

### 6. Раздел «О проекте»

Добавлен `#about` вместо прежней ссылки на подвал:

- зачем нужен Market Pulse;
- конвейер «событие → классификация → Россия → проверка исходом»;
- стек интерфейса, данных и поставки;
- автономность и бесплатные лимиты;
- правила честности, включая 60/40 и отказ от fake accuracy;
- ограничения источников и языковой модели;
- roadmap: калибровка после достаточного N, режим рынка, карта шоков и
  «машина времени».

## Что сознательно не делали

- Не добавляли новую chart-библиотеку вместо Recharts.
- Не превращали длинную страницу в роутер с отдельными URL: текущая
  одностраничная структура и hash-гид уже работают, а lazy-чанки решают
  главную проблему веса без риска сломать ссылки из Telegram и гида.
- Не прятали основные данные за мобильными вкладками. Вместо этого
  добавлены нижняя навигация, сворачиваемые фильтры и отложенная загрузка.
- Не меняли backend, публичные контракты `cached_*`, shadow-пайплайн,
  расписание pg_cron, порог 60/40 и разделение российского/глобального
  контуров.

## Проверки

Локально выполнены:

- `npm run typecheck` — успешно;
- `npm run lint` — успешно;
- `npm run build` — успешно;
- `npm audit` — 0 уязвимостей;
- Playwright QA на 1440×1000 и 375×812:
  - нет горизонтального overflow;
  - новая шапка и знак отображаются;
  - Tension показывает живые данные и корректную SVG-историю;
  - фильтры новостей работают на desktop и мобильных;
  - фильтры событий памяти отображаются с реальными counts;
  - клики по навигации приводят к `#news`, `#market-memory`, `#about`;
  - прямая ссылка `#guide-memory` открывает нужный раздел гида;
  - нижняя мобильная навигация после прокрутки остаётся внизу viewport.

Production-сборка после удаления Recharts не содержит `charts`-чанка.
Основные отложенные чанки: AnalyticsGuide, MarketMemory, NewsFeed,
AboutProject и Forecasts загружаются отдельно, а не вместе с первым экраном.

## Что нужно сделать владельцу для публикации

Это обновление фронтенда и ассетов. Supabase и GitHub Actions трогать не нужно.

1. Скачайте новый ZIP из ответа ассистента и распакуйте его.
2. Откройте GitHub-репозиторий `Clincher1/market-pulse1`.
3. Нажмите **Add file → Upload files**.
4. Перетащите **содержимое распакованной папки целиком** (не внешнюю папку
   как один объект), включая скрытую `.github`, если файловая система её
   показывает. Workflow не изменился, но полная загрузка безопаснее.
5. Дождитесь списка файлов и нажмите **Commit changes**.
6. Дождитесь нового Vercel deployment со статусом **Ready**.
7. Откройте сайт и сделайте жёсткое обновление: `Ctrl + F5`.
8. Проверьте новый favicon, знак в шапке и раздел **О проекте**.

**Не запускайте** workflow «Deploy guarded shadow pipeline»: бэкенд в этом
обновлении не менялся.

### Если Telegram показывает старое превью

Мессенджеры кэшируют OG-картинки. В метатегах уже стоит новый адрес
`og-image.png?v=20261023`, но старый пост может не обновить карточку
задним числом. Для проверки отправьте ссылку новым сообщением в «Избранное»
или другой чат после Vercel Ready. Если Telegram всё ещё показывает старую
картинку, один раз отправьте адрес сайта с хвостом `?v=20261023` и затем
опубликуйте обычный адрес новым постом.

### Необязательная финальная чистка `.bolt`

GitHub Upload не удаляет отсутствующие в ZIP файлы автоматически. Если в
репозитории останется папка `.bolt`, сайт от этого не пострадает: это
служебные файлы старого шаблона, не favicon и не превью. Для полной чистки
можно позже удалить в GitHub два файла `.bolt/config.json` и `.bolt/prompt`
по очереди через значок корзины. Это необязательно для публикации.
