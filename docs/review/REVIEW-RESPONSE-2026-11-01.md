## 2. Где формулировка сильнее проверки

1. **«Не содержит фейков».** Чтобы это утверждать, нужно смотреть, нет ли
   подмены инструмента, процента от процента, мёртвых указателей и выдуманных
   значений. Проверка «сайт = пакет» этого не покрывает: если бы ошибка была в
   обоих, она осталась бы незамеченной.
2. **«Расхождений с документацией нет».** В самом пакете, §7, перечислены
   **девять** известных неидеальностей: лента Reuters через Google News отвечает
   успешно 12 раз из 40 (сегодня), в окне семи дней лежат пять имён от
   остановленного блока прогнозов, три ряда «Памяти рынка» опираются на FRED,
   события группируются по заголовкам, а не по смыслу, и т. д. Это и есть
   расхождения — просто описанные, а не скрытые.
3. **Проверено ~6 чисел из сотен.** Не проверены те части, которые как раз
   доказывают честность: журнал самопроверок (19 из 19 в 16:25 UTC), здоровье
   24 лент (у худшей 30 % успеха — это их 503, а не наша поломка), формулы
   (пересчёт индекса напряжённости дал 15 при 118 материалах).
4. **Не отмечен дрейф снимка.** Пакет — снимок на 19:00 МСК. С тех пор: BTC
   77 920 → 77 965 → 77 995 (сейчас по Kraken 77 973), новостей в выборке
   120 → 118, статей «Памяти рынка» 7 335 → 7 351, событий 3 286 → 3 293.
   Это норма для живого сайта, но проверяющий обязан это сказать.
5. **«И его API»** — технически возможно: `/api/russia-insights` отдаётся
   текстом и читается без браузера (я его так и читал). Но в ответе нет ни
   одного числа, которое было бы **только** в API и нигде на странице, поэтому
   факт обращения к API по тексту не проверить.

Три вопроса, ответы на которые **невозможно взять из пакета** и которые нельзя
угадать — они менялись в последние часы. Ответы ниже сняты мной 01.11.2026

| Сколько новостей сейчас в выборке под шкалой напряжённости? | **118** (в пакете 120) | отвечал по пакету, а не по странице |
| Назови `generatedAt` из `/api/russia-insights` | `2026-11-01T16:41:40Z` (всегда свежий момент) | к API не обращался |

Если на все три ответа приходят актуальные числа — проверка настоящая, и тогда
его вывод можно принимать, но с поправкой из §2: «сайт совпадает с пакетом и с
первоисточниками по выборочным числам».
