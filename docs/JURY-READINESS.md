# Проверка статических документов перед публикацией

## Область изменений

Это подготовка HTML и метаданных к проверке, не изменение рыночной логики.
`data/snapshot.json`, updater, расписание, источники, запросы, миграции и история
не изменены. Новый production-деплой требует отдельного разрешения на merge PR.

- У главной полный заголовок «Market Pulse — рынки России и мира: котировки,
  источники и даты». `pageTitles.json` используется сборкой и React, поэтому
  заголовок не сокращается после запуска приложения.
- В исходном HTML: `lang="ru"`, description, production canonical, Open Graph,
  Twitter `summary_large_image`, абсолютный URL существующей PNG-карточки
  1200 × 630 и её текстовое описание. Canonical намеренно не указывает на preview.
- Главная содержит WebSite и Dataset JSON-LD. Dataset строится из того же
  проверенного файла, что и статическая таблица. `dateModified` = `exportedAt`.
  Каждое наблюдение — вложенный Dataset: identifier/инструмент, temporalCoverage
  (исходная дата наблюдения), PropertyValue со строкой точного значения и
  unitText, citation с названием/URL источника, measurementTechnique с основанием.
  Даты Yahoo остаются датами без придуманного времени, XAU сохраняет timestamp.
  Лицензии провайдеров, оценки, рейтинги и прогнозы не выдумываются.
- JSON-LD — неисполняемый data block; символ `<` экранируется в JSON для защиты
  от закрытия script данными источника. CSP не ослаблена. Проверка в Chromium
  с deployment-CSP не обнаружила policy violations.
- Сборка создаёт `sitemap.xml`, копирует `robots.txt` и создаёт `404.html`.
  Sitemap содержит только девять публичных страниц, без API, архива и 404.
- `/about` дополнена источниками ECB/Yahoo Finance/gold-api.com, формулой
  изменения, расписанием 09:10 МСК, отличием HTML-снимка от обновляемого
  кэша и дисклеймером. Тексты из `methodology.json` общие для HTML и React.
  ECB явно не включён в трёхстрочный снимок главной.
- Подписи источников, точные ссылки строк таблицы и дисклеймер находятся в HTML,
  не зависят от React. Описано, что обновление снимка требует перезагрузки страницы
  и что при неуспешной публикации остаётся предыдущая версия.
- 404 — самостоятельная страница без запуска React, с `noindex, follow` и
  ссылками на главную/методику. Vercel использует обычный `404.html`, без SPA
  catch-all rewrite. Локальный origin отдаёт неизвестные URL с настоящим HTTP 404
  и сохраняет совместимый redirect `/memory` → `/`. HTML, robots и sitemap на
  origin не кэшируются на год как immutable; XML имеет правильный Content-Type.

## Автоматические проверки

```sh
npm ci
npm test
npm run typecheck
npm run lint
npm run build
```

`tests/jury-readiness.test.mjs` проверяет готовую сборку без выполнения JavaScript:
метаданные, физическое наличие/размер og:image, источники/дисклеймер, соответствие
JSON-LD таблице, тексты методики, robots/sitemap, самостоятельную 404 и HTTP/HEAD
ответы origin. `tests/static-snapshot.test.mjs` дополнительно проверяет следующую
выгрузку без правки метаданных, сохранение точности и экранирование JSON-LD.

Браузерная проверка начального документа:

```sh
DOCUMENT_ORIGIN=http://127.0.0.1:8080 node scripts/check-initial-document.mjs
```

Браузерные зависимости изолированы в `.local/feature-browser` (не зависимости
приложения). API/внешние запросы во время проверки заблокированы. Это не проверка
текущих рыночных значений или доступности провайдеров. Проверены 360/768/1024/1440 px,
JavaScript off, отказ загрузки entry и нормальный запуск, в двух раундах. Отдельно
проверены 404, title после запуска React и методика с JS/без JS на тех же ширинах.
Локальные логи/скриншоты лежат в `.local/jury-readiness/` и не включаются в Git.

## Чек-лист с телефона

До merge используйте preview из PR. Основной домен продолжает показывать старую
версию до отдельного разрешения на публикацию.

- [ ] Открыть главную; название вкладки — полный заголовок Market Pulse.
- [ ] В настройках браузера временно отключить JavaScript и перезагрузить главную:
  есть «Статический снимок данных», три строки с единицами, датами, источниками,
  временем выгрузки и предупреждением о задержке. Таблица прокручивается внутри
  страницы, а не растягивает экран.
- [ ] Без JavaScript открыть `/about`: есть ECB, Yahoo Finance, gold-api.com,
  ссылки на источники, формула, 09:10 МСК, отличие снимка от текущих данных,
  объяснение exportedAt и дисклеймер. Вернуть JavaScript и проверить те же тексты.
- [ ] Открыть выдуманный адрес, например `/jury-test-not-found`: видна своя 404,
  работают ссылки на главную и методику. Перезагрузка не превращает её в обзор.
- [ ] Открыть `/robots.txt` и `/sitemap.xml`: это текст/XML, не главная приложения;
  адрес sitemap и canonical используют production-домен.
- [ ] Поделиться ссылкой в мессенджере: есть название, описание и картинка. Старое
  превью может сохраняться в кэше мессенджера. Поля карточки отдельно проверены
  в HTML; появление карточки у конкретного сервиса не гарантируется.

Наличие метаданных/JSON-LD не гарантирует индексацию, позицию или rich result.
Полная проверка нового live production возможна только после одобренного merge.
