# Цикл исправлений и повторных аудитов Market Pulse

## Статус

**Остановочный критерий достигнут: два последовательных комплексных прохода по всем десяти разделам без новых подтверждённых дефектов в описанном ниже покрытии.** Ранние проходы с найденными дефектами в эти два не включены. Это не утверждение об отсутствии любых возможных ошибок и не сертификат достоверности внешних поставщиков.

Последнее изменение исполняемого кода — `2ba414e6e3507940783d321206818ee215203d93`; `568db0e78b7455cb0eff08f688fe05c5e7005d5e` только синхронизирует имя файла миграции с уже применённой версией. После исправления повторены локальные проверки, браузерные сценарии и live-сверка.

Этот документ дополняет исходный [повторный аудит](./AUDIT-REPEAT-2026-11-20.md), а не переписывает его наблюдения задним числом. Времена ниже — UTC из ответов проверяемой инфраструктуры.

## Исправления

| Проблема | Исправление и проверка |
| --- | --- |
| Золото сравнивалось с предпоследним закрытием | Writer использует последнее завершённое закрытие для более поздней котировки. Регрессия проверяет реальную сборку строки, а не только функцию выбора базы. |
| Мониторинг пропускал Gold и BTC | Проверяются все пять рядов: тип значения, даты, база и допустимая погрешность округления цены. Отсутствие дат не считается успешной сверкой. |
| Базы сравнения смешивались в описаниях | Главная и бриф выбирают лидера по двум датированным закрытиям; карта дня — котировка к предыдущему закрытию. Периоды, точки и формулы названы явно. |
| Будущие снимки теряли дату последней точки | Writer снимков сохраняет пару `last`/`last_date`. Некорректная или отсутствующая дата остаётся неизвестной, а не заменяется временем котировки. |

| Подпись инфляции обещала прошлый месяц | Указан фактически последний опубликованный месяц; значение из источника не подменяется ожидаемым. |

| Старые паспорта сохраняли неверный процент золота | Исходные записи не изменены. На странице опубликовано предупреждение о возможной неверности старых процентов и лидера. |
| API-публикация Edge Functions принималась, но функции не стартовали | Публикация заменена на настоящий CLI bundle после tests/typecheck/lint/build/Deno. Проверяется runtime, а не только `ACTIVE`. |
| Отсутствие запросов по расписанию ошибочно давало `502`, `0/5`, `errors: []` | Добавлен явный no-op `200`, `skipped: true`, `reason: all_sources_gated`, причины каждого слота; даты кэша не меняются. Handler-регрессия запрещает внешние запросы и запись котировок в таком сценарии. Настоящие неудачные попытки по-прежнему возвращают ошибку. |
| pg_net обрывал ожидание writer через 5 секунд | Миграция `20261120152742_asset_cron_response_timeout` увеличила ожидание до 120 секунд, сохранив расписание, URL и авторизацию. Сам writer миграцией не вызывается. |

## Почему предварительные проходы не засчитаны

Первые обходы интерфейса имели ноль формальных находок, но визуальный просмотр обнаружил сжатие мобильного брифа. После его исправления live-проверка нашла `503 BOOT_ERROR` у API-публикации функций. После CLI-публикации проверка следующего планового запуска обнаружила ложный `502` при закрытом шлюзе источников и 5-секундный таймаут pg_net. Каждый такой результат обнулял счётчик чистых полных аудитов.

Ноль находок на фикстурах сам по себе не считается полным чистым аудитом.

## Методика двух заключительных проходов

Каждый проход состоит из независимых слоёв:

1. Все десять основных маршрутов: `/`, `/passport`, `/russia`, `/world`, `/brief`, `/news`, `/memory`, `/guide`, `/about`, `/status`.
2. Реальный Chromium локальной production-сборки на 360 и 1280 px. Сетевые данные здесь контролируемые фикстуры: это проверка интерфейса, а не доказательство доступности production API.
3. В браузере: JS-ошибки, переполнение страницы, наличие основного содержимого и заголовков, ссылки `undefined`, узкие длинные абзацы; мобильное меню, закрытие после перехода и видимый текущий раздел; избранное после перезагрузки; окно/шкала сравнения; разворот и фильтр новостей. Reduced motion включён.
4. Отдельное чтение опубликованных страниц и фактических данных/API; расчёты, даты, источники, формулы и сохранённый результат selfcheck; плановые запуски writer.
5. `npm test`, typecheck, lint, production build, Deno check серверных функций.
6. Повторный просмотр скриншотов. Дополнительно выполнен обход всех 20 сочетаний маршрут/ширина при намеренном `503` API: без необработанных JS-ошибок и переполнения; это не утверждение об отсутствии всех возможных отказов.

Браузер в sandbox не имеет прямого доступа ко всем внешним хостам; поэтому live-данные проверяются отдельно через доступные инструменты, а не скрыто подменяются успешным mock-результатом.

## Сохраняемые ограничения

- Старые проценты/выбор лидера в неизменяемых паспортах могут быть неверны. Они не исправляются задним числом; предупреждение видно в интерфейсе.
- Архив прогнозов: 150 записей, 56 рассчитанных исходов, 94 без исхода. Незавершённость явно показана; новые прогнозы не возобновлены, записи не удалены.
- Новый `last_date` в writer покрыт регрессией и опубликован, но первая новая утренняя production-вставка ещё не наблюдалась. Существующий baseline намеренно не перезапускался ради проверки.
- Два чистых прохода означают отсутствие новых подтверждённых дефектов в описанном покрытии и наблюдённом окне. Это не гарантия вечной доступности поставщиков, не полный пентест и не проверка всех внешних ссылок/устройств.
