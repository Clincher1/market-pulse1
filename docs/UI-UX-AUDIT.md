# UI/UX-аудит Market Pulse

## Краткий вывод

**Исходная экспертная оценка: 6,5/10.** Это оценка дизайна, а не сертификат WCAG и не оценка точности рыночных данных.

Сильные стороны: самостоятельные адреса разделов, понятная иерархия, один главный CTA первого экрана, собственная визуальная идентичность, локальный Inter, отсутствие трекеров. Основные дефекты — контраст активной навигации, маленькие независимые цели нажатия, клавиатурное поведение мобильного меню, мелкие пояснения и одинаковые метаописания.

Аудит охватывает `/`, `/passport`, `/russia`, `/world`, `/brief`, `/news`, `/guide`, `/about`, `/status`; ширины **360 / 768 / 1024 / 1440 px**. Исходная браузерная матрица: 36 случаев, сохранена в [ui-ux-before/report.json](audit-evidence/ui-ux-before/report.json). Отсутствие нарушений выбранных axe-правил не опровергало ручной расчёт плохого контраста CSS-градиентов.

### Пять наиболее важных проблем и эффект исправления

1. **Недостаточный контраст активной навигации** → текст остаётся читаемым на всех точках градиента, минимум 4,5:1.
2. **Маленькие независимые цели нажатия** → 44×44 px вместо примерно 24–43 px, меньше промахов.
3. **Escape не закрывал мобильное меню** → предсказуемое закрытие и возврат фокуса на кнопку.
4. **Пояснения 8,48–11 px, длинные строки и устаревшая подпись источника** → важные подписи от 12 px, проза до 72ch, актуальный текст без замены данных.
5. **Несогласованные оси контейнеров и одинаковые описания маршрутов** → max-width 1400 px, единый ритм и отдельные сниппеты страниц.

## Диагностика по чек-листу (до исправлений)

| Пункт | Оценка | Где и почему |
| --- | --- | --- |
| Сетка и общие оси | Требует доработки | Header ограничен 1500 px, main — 1400 px; footer имеет другую схему внешнего/внутреннего отступа. На широком экране оси расходятся. |
| 12 колонок | Профессионально для данного продукта | Адаптивные Grid/Flex-сетки карточек; буквальная 12-колоночная сетка не нужна каждой таблице. Перестройка ради числа колонок ухудшила бы плотный финансовый интерфейс. |
| Ритм 4/8 px | Требует доработки | В основном выдержан; карточки «Откуда мы знаем» имеют 14 px padding, переходы между крупными блоками обзора неоднородны. |
| Иерархия заголовков и CTA | Профессионально | Первый экран: выразительный H1, пояснение, один главный CTA «Смотреть сводку дня»; вторичная методология визуально тише. |
| Не более двух шрифтов | Профессионально | Основной Inter загружается локально; системные fallback не являются дополнительным бренд-шрифтом. |
| Размер пояснений | Грубая ошибка | Подпись маршрута на мобильном около 8,48 px; пояснения источников/графиков 11 px. Важный смысл требует слишком большого усилия. |
| Интерлиньяж 1,4–1,6 | Требует доработки | Основной текст преимущественно `leading-relaxed`; пояснениям нужен единый читаемый ритм. Display-заголовки и числовые ячейки оцениваются отдельно. |
| Длина строки 60–80 знаков | Требует доработки | Пояснения MarketDesk и некоторых рыночных блоков растянуты на всю ширину 1200+ px. |
| WCAG-контраст текста 4,5:1 | Грубая ошибка | Белый текст активного desktop-пункта «Сводка» на оранжевом градиенте: 2,35–2,82:1; также провалы у России, мира, новостей и hover «Ещё». |
| Воздух между крупными секциями | Требует доработки | У обзора нужен стабильный ритм 48 px mobile / 64 px desktop. Отступы лендинга 80–120 px нельзя механически применять между всеми карточками дашборда. |
| Внутренние отступы карточек | Требует доработки | Поддерживающие карточки «Откуда мы знаем»: 14 px тесно для текста и ссылки. |
| Адаптив 360/768/1024/1440 | Профессионально по геометрии | Исходные 36 случаев без горизонтального переполнения; это не доказывает удобство маленьких кнопок. |
| Независимые touch-цели 44×44 | Требует доработки | Quick-nav 40 px, burger 43 px, guide-пилюли 36 px, FAQ 24–28 px, мобильные ссылки орбиты около 24 px, footer 36/40 px. Checkbox 18 px внутри кликабельного label 44 px — не дефект. |
| Бургер и клавиатура | Требует доработки | Escape не закрывал мобильное меню в 18/18 доступных мобильных случаях. У desktop «Ещё» это поведение уже было. |
| Hover / active / focus | Требует доработки | Состояния и reduced-motion уже предусмотрены; надо сохранить их при исправлении контраста и добавить возврат фокуса мобильному disclosure. |
| Disabled / переходы 150–300 мс | Профессионально в основных контролах | MarketDesk имеет disabled и focus; интерактивная навигация использует переходы 150–200 мс. Декоративная анимация не обязана длиться 150–300 мс. |
| Навигация не более 7 пунктов | Требует доработки | Desktop уже группирует дополнительные ссылки в «Ещё»; мобильный полный список следует разделить на рынки/публикации и информацию о сайте. |
| Активный раздел, логотип, выходы | Профессионально | Есть `aria-current`, логотип ведёт на обзор, тематические страницы связаны с гидом и footer. |
| Единые кнопки, карточки, иконки | Требует доработки | Общий язык скруглений и Lucide выдержан; desktop-цвета маршрутов расходились с семантикой мобильных тем. |
| Палитра и радиусы | Профессионально в основе | Не нужен редизайн всех карточек; достаточно исправить контраст и согласовать route-палитру. |
| Понятность первого экрана за 3 секунды | Профессионально | Рынки, источники, время наблюдения и отсутствие прогнозов обозначены без прокрутки. Трёхсекундный пользовательский тест с респондентами не проводился. |
| Один главный CTA | Профессионально | Сводка — первичное действие; методология — вторичное. Не добавлять конкурирующие акцентные кнопки. |
| Понятный и актуальный текст | Требует доработки | `/about` → «Как собираем и проверяем данные»: устаревшее описание истории золота через Twelve Data. |
| Favicon и бренд-шрифт | Профессионально | Favicon, manifest и self-hosted Inter уже есть; повторная генерация не нужна. |
| Уникальные title | Профессионально | 9 разных заголовков в исходной матрице. |
| Уникальные description | Требует доработки | Одинаковое описание на всех 9 маршрутах, включая статические HTML для роботов. |
| Alt и оптимизация изображений | Профессионально в проверенной области | Браузер не нашёл img без alt; основной декор — SVG. Это не утверждение о Lighthouse/performance всех страниц. |
| Неработающие ссылки | Профессионально в исходной внутренней выборке | 16 внутренних адресов ответили 200. Исходный скрипт не проверял наличие fragment-id; финальный проверяет. Внешние издатели и точность их материалов — отдельный аудит. |
