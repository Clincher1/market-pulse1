# Копирование котировки и CSV графика

## Что опубликовано

В раскрытой карточке актива раздела «Мир»:

- **Копировать котировку** — инструмент, показанная цена, единица, исходная дата/время наблюдения с часовым поясом, название источника и ссылка. Время обновления кэша не заменяет дату наблюдения. При отсутствии цены/источника/даты кнопка недоступна. При запрете Clipboard API появляется поле ручного копирования, а не ложный успех.
- **Скачать точки графика · CSV** — все фактические точки текущего диапазона 30/90/180 календарных дней, а не только последние 30 строк таблицы. Сохраняются даты, исходная числовая точность, единица, инструмент, ряд, поставщик, его обозначение, ссылка и частота. Формат: UTF-8 BOM, CRLF, разделитель `;`, десятичная запятая; экранирование CSV и защита строковых полей от формул электронных таблиц.

Экспорт работает только для уже загруженного разрешённого публичного ряда. Нет новых запросов к поставщикам, расширения выборок/прав доступа, миграций, изменений базы, телеметрии, cookies или новых зависимостей приложения. Недатированный резервный график нельзя выгрузить как датированную историю. Для золота явно указаны собственные наблюдения завершённых UTC-суток, не официальный close.
