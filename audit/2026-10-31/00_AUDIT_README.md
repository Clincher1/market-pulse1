## 7. Как читать пакет независимому проверяющему

1. Начать с `01_SITE_INVENTORY.md` — что вообще есть на сайте.
2. Взять любой показатель и пройти `02_DATA_SOURCES.md` → `07_DATA_FLOW.md` → `06_API_RESPONSES/`.
3. Формулы сверять по `04_CALCULATIONS_AUDIT.md`, даты — по `05_FRESHNESS_AUDIT.md`.
4. Проверить утверждения аудита можно двумя командами в `SOURCE_CODE/`: `npm ci && npm test` (68 тестов) и `cd supabase/functions && deno check */index.ts _shared/*.ts`.
5. Всё, что помечено `UNVERIFIED`, — не проверено, а не «наверное верно».
